# USB通信工具

这是一个基于PyQt5的USB通信GUI工具，支持与VID为0x1514、PID为0x1000的USB设备进行通信。

## 功能特性

- 🔌 **热拔插支持**: 自动检测USB设备的连接和断开
- 📊 **状态指示**: 实时显示设备连接状态（绿色=已连接，红色=未连接）
- 📡 **双设备支持**: 支持同时连接两个WinUSB设备
- 💬 **消息通信**: 支持向设备发送消息和接收设备消息
- 🎨 **现代化界面**: 美观的PyQt5界面设计
- 📝 **消息记录**: 实时显示发送和接收的消息历史

## 系统要求

- Windows 10/11
- Python 3.7+
- 支持VID:0x1514, PID:0x1000的USB设备

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行主程序：
   ```bash
   python gui.py
   ```

2. 连接USB设备：
   - 将支持VID:0x1514, PID:0x1000的USB设备插入电脑
   - 界面会自动检测设备连接状态
   - 状态指示灯会显示绿色表示设备已连接

3. 发送消息：
   - 在"目标设备"下拉框中选择要通信的设备
   - 在"发送消息"输入框中输入要发送的消息
   - 点击"发送"按钮或按回车键发送消息

4. 查看消息记录：
   - 所有发送和接收的消息都会在"消息记录"区域显示
   - 不同类型的消息用不同颜色区分：
     - 🔵 蓝色：发送的消息
     - 🟢 绿色：接收的消息
     - 🟠 橙色：系统消息（设备连接/断开）
     - 🔴 红色：错误消息

## 技术架构

### USB通信模块 (`usb_communication.py`)
- 基于pyusb和win32api实现USB设备通信
- 支持设备热拔插检测
- 多线程处理设备监控和消息接收
- 使用PyQt5信号机制与GUI通信

### GUI界面 (`gui.py`)
- 基于PyQt5构建现代化界面
- 实时状态指示器
- 消息发送和接收功能
- 彩色消息记录显示

## 注意事项

1. **管理员权限**: 某些USB设备可能需要管理员权限才能访问
2. **驱动安装**: 确保USB设备已正确安装WinUSB驱动
3. **设备兼容性**: 仅支持VID:0x1514, PID:0x1000的设备
4. **libusb**: 确保libusb-1.0.dll文件在程序目录中

## 故障排除

### 设备无法连接
- 检查设备VID/PID是否正确
- 确认设备驱动已正确安装
- 尝试以管理员身份运行程序

### 消息发送失败
- 确认目标设备已连接
- 检查设备是否支持当前通信协议
- 查看错误日志获取详细信息

### 程序启动失败
- 确认所有依赖包已正确安装
- 检查Python版本是否兼容
- 确认libusb-1.0.dll文件存在

## 开发说明

### 添加新设备支持
1. 修改`usb_communication.py`中的VID和PID
2. 更新设备名称映射
3. 根据需要调整通信协议

### 自定义界面
1. 修改`gui.py`中的UI布局
2. 调整样式表以改变界面外观
3. 添加新的功能组件
